# Session display

An interactive replay of one Claude Code session: Fable 5.1 turning the
construction bid set for Hayward Fire Station #6 and its Fire Training
Center into docs, a sheet viewer, a reprographics PDF, a campus map and a
3D snow globe (2026-10-15). One self-contained page, `index.html`.

Live: https://nicksramcik.github.io/session-display/
